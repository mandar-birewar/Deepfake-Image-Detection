Deepfake Image Detection using Transfer Learning

This project presents a deepfake image detection system developed using deep learning and transfer learning techniques. The objective of the system is to identify whether a facial image is real or manipulated using deepfake generation methods. The model is trained on facial forgery datasets and learns visual inconsistencies, synthetic artifacts, and abnormal facial patterns commonly introduced during deepfake generation. The implementation uses pretrained convolutional neural network architectures such as ResNet for feature extraction and classification. Image preprocessing techniques including resizing, normalization, and augmentation are applied to improve model generalization and robustness. The system is implemented using Python, PyTorch, OpenCV, NumPy, and Scikit-learn libraries. Performance evaluation is carried out using metrics such as Accuracy, Precision, Recall, ROC Curve, and Confusion Matrix. The proposed model achieves high classification accuracy and demonstrates effective detection of manipulated facial images. This project can be further extended for real-time deepfake detection, video-based forgery analysis, and deployment in cybersecurity and digital media verification systems.
